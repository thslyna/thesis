# Data

This directory is reserved for the datasets used in this research.

## Data sources

The thesis uses three main categories of data:

- Aviation and flight operational data.
- Meteorological observations.
- Surface road traffic data from Istanbul Metropolitan Municipality (IBB).

## Data availability

Raw datasets are not included in this GitHub repository because of their size, access conditions, and potential data-provider restrictions.

API credentials and other sensitive information must not be committed to this repository.

The dataset description, collection process, and preprocessing methodology are documented in the thesis.
